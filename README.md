# 🏨 Hotel Zante Clone

A responsive front-page clone of the Hotel Zante website built using HTML, CSS, and Bootstrap 5.

## 🚀 Live Demo

🔗 https://syedabsar99.github.io/hotel-zante-clone/

## 📂 GitHub Repository

🔗 https://github.com/syedabsar99/hotel-zante-clone

## ✨ Features

- Responsive navigation bar
- Dropdown menus
- Bootstrap carousel/hero section
- Hotel booking form UI
- Room showcase section
- Services section
- Video background section
- Tourist destinations showcase
- Customer reviews section
- News/blog cards
- Responsive footer
- Mobile-friendly design

## 🛠️ Built With

- HTML5
- CSS3
- Bootstrap 5
- Remix Icons
- VS Code
